# GymFix — Phase 7: Usability Test Plan

**Project:** GymFix
**Phase:** 7 — Usability Testing & Iteration
**Status:** Planned
**Prototype:** https://gymfix-demo.lovable.app/

## 1. Research Objective

Evaluate whether first-time users can independently complete GymFix's core equipment fault reporting and maintenance workflows.

## 2. Research Questions

1. Can members submit fault reports without assistance?
2. Can members locate and understand ticket status?
3. Can staff assign maintenance tickets efficiently?
4. Can technicians update repair progress?
5. Which parts of the interface create confusion or delays?

## 3. Methodology

- Method: Moderated task-based usability testing
- Target sample: 5 participants
- Recruitment: Convenience sample, preferably gym users
- Duration: Approximately 15–20 minutes per participant
- Environment: Published Lovable prototype
- Data: Fictional gym equipment and maintenance tickets

## 4. Test Tasks

### Task 1 — Fault Reporting

Scenario: You encounter a broken treadmill. Use GymFix to report it.

Measure:
- Task completion
- Completion time
- Errors
- Ticket reference visibility

### Task 2 — Ticket Tracking

Scenario: You previously reported faulty equipment. Find its current maintenance status.

Measure:
- Correct status identification
- Completion time
- Navigation errors

### Task 3 — Technician Assignment

Scenario: You are gym staff. Find a newly reported ticket and assign a technician.

Measure:
- Assignment success
- Completion time
- Navigation errors

### Task 4 — Repair Status Update

Scenario: You are a technician. Find your assigned ticket and update its repair progress.

Measure:
- Task completion
- Completion time
- Status comprehension

## 5. Proposed Success Metrics

| Metric | Target |
|---|---|
| Reporting task success | >= 90% |
| Median reporting time | <= 60 seconds |
| Status lookup success | >= 90% |
| Staff assignment success | >= 90% |
| Critical usability blockers | 0 |

Targets are provisional and not actual results.

## 6. Data Collection

For each task, record:
- Independent success / assisted completion / failure
- Completion time
- Errors and hesitation
- Observed usability issues
- Participant feedback

## 7. Post-Test Questions

1. How easy was GymFix to use? (1–5)
2. Which part was most confusing?
3. What would you improve first?

## 8. Testing Protocol

1. Explain the study and obtain consent.
2. Ask participants to complete tasks without guidance.
3. Observe actions and record completion times.
4. Avoid leading participants toward the correct interface.
5. Ask follow-up questions after task completion.
6. Reset demo data between participants.

## 9. Limitations

- Small, non-representative sample.
- Demo mode uses browser-based storage.
- No real gym deployment.
- Results will reflect prototype usability, not product-market fit.

## 10. Next Steps

Conduct usability sessions, analyse results, prioritise findings, and document any product iterations.
